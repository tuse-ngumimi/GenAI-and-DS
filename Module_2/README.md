# Real Estate Pricing Analysis

A Python script that loads real estate data, computes descriptive 
statistics, and analyses relationships between numeric features.

## What This Script Does

- Computes mean, median, and mode for key numeric columns
- Computes standard deviation for numeric features
- Generates a correlation matrix to reveal relationships 
  between numeric variables
- Prints the most frequent values for selected categorical fields

## Dataset

**USA Real Estate Dataset** by Ahmed Shahriar Sakib  
Source: [Kaggle](https://www.kaggle.com/datasets/ahmedshahriarsakib/usa-real-estate-dataset)

## Library Used

- Pandas
